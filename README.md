# MYOMORPH-project

MYOMORPH-MK. 1(실제로 작동 가능한 근골격 티타늄 슈트)이 한 사람의 몸 위에 조립되는 과정을 보여 주는 스크롤형 인터랙티브 3D 웹 경험.

- **새 세션 시작**: [`docs/HANDOFF.md`](docs/HANDOFF.md)
- 마스터 플랜: [`docs/PLAN.md`](docs/PLAN.md) (v3.0)
- 레퍼런스 작성 가이드: [`docs/reference/GUIDE.md`](docs/reference/GUIDE.md) · 처리 절차: [`docs/INTAKE.md`](docs/INTAKE.md)
- 브리프: [`docs/brief/`](docs/brief/)

현재 상태 (2026-10-03): P0 완료, P1 R1·R2 완료. 마네킹 기반 슈트 디자인을 폐기하고, 도하의 새 레퍼런스로 슈트를 다시 만들 준비를 마쳤다. 새 레퍼런스를 기다리는 중.

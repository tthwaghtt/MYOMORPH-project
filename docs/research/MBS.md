# MBS: MYOMORPH Blender Standard v1.0

> G0 조사([`blender-methodology.md`](blender-methodology.md))에서 도출한 작업 규약. MYOFORGE 파이프라인의 모든 산출물은 이 규약을 따르고, 🤖 표시 규칙은 `myoforge/lint/`가 자동 검사한다(P2부터).  
> **적용 버전** Blender 5.2.1 LTS (bpy, Python 3.13). 버전을 올릴 때는 [`scripts/`](scripts/README.md)를 다시 돌려 차이를 기록한다.

**심각도**: 🔴 오류(빌드 실패) · 🟡 경고(리포트, 리뷰 필요) · ⚪ 권장

---

## 1. 명명 (N)

| ID | 규칙 | 심각도 | 🤖 |
|---|---|---|---|
| N01 | `lower_underscore_case`. 접두사/접미사와 부품번호 코드만 대문자. 공백, 특수문자(`+=#^*&$()?!.`) 금지 | 🔴 | 🤖 |
| N02 | 대시(`-`)는 접두사와 계층 구분 전용, 밑줄(`_`)은 공백 대체 | 🔴 | 🤖 |
| N03 | 오브젝트 접두사: `GEO`(렌더 지오메트리), `RIG`(아마추어), `LGT`(조명), `ENV`(환경), `CAM`(카메라), `HLP`(헬퍼, 렌더 제외), `WGT`(본 셰이프), `MOLD`(근육/외형 몰드, 익스포트 제외) | 🔴 | 🤖 |
| N04 | 부품 오브젝트 = `GEO-` + 부품번호 `MM1-[부위]-[근육/부품]-[L\|R\|C]-[NN]` (PLAN §5.1) | 🔴 | 🤖 |
| N05 | 블렌더 자동 접미사 `.001` 금지 (중복 이름 = 파이프라인 버그) | 🔴 | 🤖 |
| N06 | 메시, 재질, 이미지 데이터블록 이름에도 소속을 넣는다: 메시 `ME-MM1-...`, 재질 `MA-[재질키]`(예: `MA-ti64_beadblast`), 이미지 `IM-[부품]-[맵]` | 🟡 | 🤖 |
| N07 | 컬렉션: 루트 `CH-mm1`, 하위 `CH-mm1-[서브시스템]`(예: `CH-mm1-MYO`, `CH-mm1-OS`) → PLAN §5.2 트리와 일치 | 🔴 | 🤖 |
| N08 | 본: `DEF-`(변형/부품 페어런트), `MCH-`(기구 계산), `CTL-`(조작), `ORG-`(원본 기준). 좌우는 `.L`/`.R` 접미사(블렌더 미러 규칙) | 🔴 | 🤖 |

## 부록: 린터 구현 메모 (`myoforge/lint/`, P2)

- 실행: `python -m myoforge.lint <blend or stage-output>` → JSON 리포트(규칙 ID, 대상, 심각도, 메시지) + 사람이 읽는 요약.
- 🔴가 하나라도 있으면 다음 단계로 진행하지 않는다(파이프라인 게이트).
- 구현 순서: N(명명) → U(트랜스폼) → M01~M02(메시 무결성) → C(색 관리) → E(익스포트) → 나머지.
- 각 규칙은 고의로 위반한 작은 테스트 장면으로 단위 테스트한다.

# 작업량 기록 (토큰 · 생각 · 시간 · 비용)

도하 요청(2026-10-02): 프로젝트 전체에 든 토큰과 작업 시간을 추적해서 **P7 발행 후 최종 보고**한다.

- 원천: Claude Code가 세션 기록에 남기는 `cost-state` (하네스 공식 집계). 스크립트: [`tools/session_usage.py`](../tools/session_usage.py)
- 각 게이트(G0~G7)를 마칠 때 `python3 tools/session_usage.py --append "<게이트>"` 로 아래 표에 스냅샷을 추가한다.
- 한 세션의 값은 누적값이다. 같은 세션의 스냅샷은 마지막 것만 유효하고, 세션이 여러 개면 세션별 마지막 값을 더한다.
- 용어: **생각 토큰** = 답하기 전 내부 추론. **모델 생각·생성 시간** = 모델이 생각하고 답을 쓰는 데 걸린 시간. **도구 실행 시간** = 렌더, 설치, 검색 등 명령 실행 시간. **세션 활성 시간** = 세션이 실제로 돌아간 시간(도하를 기다린 시간 제외).
- 입력 토큰의 대부분은 캐시 읽기다(이전 대화를 매 호출 다시 읽는 비용, 단가가 낮음).

|---|---|---:|---:|---:|---:|---:|---:|---:|---:|

# MYOMORPH-MK. 1 레퍼런스 작성 가이드

> **도하용** · 2026-10-03 · Claude 작성
> **목적**: Claude가 레퍼런스의 모든 선을 정확히 읽고, 판 하나하나를 도면 그대로 3D로 만들 수 있게 그리는 방법.
> **템플릿**: [`template/`](template/) (도하 몸 치수로 만든 정사영 밑그림, SVG + PNG)

---

## 0. 한눈에 보는 체크리스트

1. **같은 자세, 같은 축척**으로 모든 뷰를 그린다. 템플릿을 밑그림으로 쓰면 자동으로 맞는다.
2. 뷰는 최소 **정면, 후면, 측면(팔 없이), 팔 4면, 다리 안쪽, 헬멧 4면**이다(§4).
3. 선은 **의미별로 색과 레이어를 나눈다**(§5).
   - 검정 굵은 선 = 판과 판 사이 틈
   - 파랑 가는 선 = 한 판 안의 꺾임
   - 빨강 점선 = 가려진 선과 겹침
   - 초록 = 나사·통풍구·조명
4. **판 윤곽은 닫힌 선**으로 그리고, 선끼리 정확히 만나게 한다. 해칭(음영 선)은 넣지 않는다.
5. 원근 없이 **정사영**으로 그린다. 정면은 정면 그대로, 측면은 정확히 90°에서 본다.
6. 가능하면 **벡터(SVG)**로 저장하고, 안 되면 레이어별 PNG로 저장한다(§10).
7. 시간이 되면 굽힌 자세, 단면, 상세도를 더한다(§4 권장).

## 1. 왜 이 규칙이 필요한가

지난 디자인이 지저분했던 원인은 세 가지다.

| 원인 | 결과 | 이번 규칙 |
|---|---|---|
| 정면 한 장과 측면 한 장뿐. 팔·다리 안쪽, 옆면, 뒷면이 없음 | Claude가 보이지 않는 면을 추측으로 채움 | 모든 면이 보이는 뷰 세트(§4) |
| 선의 의미가 구분되지 않음. 판 경계, 꺾임, 해칭, 두 줄 선이 모두 같은 파란 선 | 음영 선까지 이음선이 되어 판이 잘게 쪼개짐 | 의미별 색·굵기·레이어(§5) |
| 래스터 이미지와 뷰마다 다른 축척·자세 | 경계가 계단 모양이 되고, 뷰끼리 위치가 어긋남 | 템플릿, 같은 자세, 벡터(§3, §6, §10) |

이번에는 **마네킹을 부풀린 껍데기를 쓰지 않고**, 도하의 레퍼런스에서 판을 하나씩 직접 만든다. 그래서 레퍼런스가 곧 설계도다. 템플릿에 들어 있는 몸은 **치수와 맞춤을 확인하는 밑그림**일 뿐이고, 디자인은 100 % 도하의 선이다.

- **3D가 편하다면**: Blender Grease Pencil이 정확도 최고다.

## 3. 템플릿 사용법

`template/` 폴더의 세 장(각각 SVG와 PNG).

| 파일 | 내용 |
|---|---|
| `template_1_body` | 정면, 측면(왼쪽, 팔 없이, 팔 위치는 점선), 후면 |
| `template_2_limbs` | 왼팔 4면(앞, 뒤, 바깥, 안쪽; 곧게 세움), 왼다리 안쪽, 몸 전체 윗면 |
| `template_3_head` | 머리 정면, 측면, 후면, 윗면 |

- **축척**: SVG 1 단위 = 1 mm, 실제 크기다. PNG는 1, 2장이 2 px/mm, 3장이 4 px/mm.
- **자세**: 위팔 30° 벌린 A자세, 팔꿈치는 곧게 편다. 몸은 바닥에서 35 mm 위(부츠 밑창)에 선다.
- **레이어**: `00~06`은 밑그림이니 잠근다. 그림은 `10~15` 레이어에 그린다.

| 밑그림 표시 | 뜻 |
|---|---|
| 회색 면 | 도하의 몸(CORPUS 분석 치수: 키 178.0 cm, 팔 너비 182.0 cm, 가슴 93.1 cm, 허리 71.0 cm) |
| 청록 점선 | **판 바깥면 최소선**(피부 + 12 mm). 판은 이 선 바깥에 있어야 한다 |
| 자홍 + | 관절 중심(어깨, 팔꿈치, 손목, 고관절, 무릎, 발목). 디스크·꺾임·판 나눔의 기준 |
| 회색 가로선 | 높이 기준선(정수리, 눈, 턱, 어깨, 가슴, 팔꿈치, 허리, 손목, 가랑이, 무릎, 복사뼈, 발바닥, 바닥). **모든 뷰에서 같은 높이에 같은 판 경계가 오도록** 맞추는 데 쓴다 |
| 주황 글씨 | 그 자리 판 아래에 들어갈 장치와 필요한 깊이(§8) |

템플릿을 쓰지 않는다면 최소한 이것만 지킨다.
- 모든 뷰를 **같은 축척**으로 그리고, 축척 막대(예: 100 mm)를 넣는다.
- 정수리, 어깨, 허리, 가랑이, 무릎, 발바닥 높이선을 모든 뷰에 가로로 긋는다.

## 4. 무엇을 그릴까 (뷰 세트)

### 필수

| # | 뷰 | 왜 필요한가 |
|---|---|---|
| 1 | **정면** | 폭, 판 배치 |
| 2 | **후면** | 등판, 엉덩이, 종아리 뒤, 목 뒤 |
| 3 | **측면 (바깥, 팔 없이)** | 앞뒤 깊이, 옆면 판. 팔을 빼야 옆구리와 몸통 옆면이 보인다 |
| 4 | **팔 4면** (앞, 뒤, 바깥, 안쪽) | 팔 안쪽과 겨드랑이 쪽은 다른 어떤 뷰에도 보이지 않는다 |
| 5 | **다리 안쪽** | 허벅지 안쪽, 무릎 안쪽, 종아리 안쪽 |
| 6 | **헬멧 4면** (정면, 측면, 후면, 윗면) + **얼굴(PERSONA)** | 헬멧은 가장 가까이 보이는 부품이다 |

### 권장 (정확도와 멋을 크게 올린다)

| # | 뷰 | 왜 |
|---|---|---|
| 7 | 윗면 (어깨판, 헬멧 윗면) | 어깨판이 위에서 어떻게 생겼는지 |
| 8 | 손 (손등, 손바닥, 옆), 부츠 (옆, 위, 밑창) | |
| 9 | **단면** (가슴, 허리, 엉덩이, 허벅지, 무릎, 종아리, 위팔, 전완 높이의 가로 단면) | 판이 얼마나 솟고 꺾이는지, 판 두께와 겹침이 한 번에 보인다 |
| 10 | **굽힌 자세** (팔꿈치 90°, 무릎 90°, 팔 들기 90°, 스쿼트) | 움직일 때 판이 어떻게 미끄러지고 겹치는지 |
| 11 | 상세도 (어깨, 가슴, 등판, 관절 디스크, 전완 툴 베이 등) | 지난 도면의 상세 박스처럼 |
| 12 | 분위기 그림 (3/4 시점, 원근 있어도 됨) | 재질과 분위기 참고용. 치수로는 쓰지 않는다 |

**좌우 대칭**이면 한쪽만 정밀하게 그리고 가운데선을 표시하면 된다. **비대칭인 곳**(예: 오른 전완 툴 베이, 왼 전완 교체 포트)은 따로 표시한다.

## 5. 선 규칙 (가장 중요)

| 레이어 | 색 · 굵기 | 의미 | 예 |
|---|---|---|---|
| `10 panel edges` | **검정, 굵게** (실제 크기 기준 약 1~1.5 mm) | **판과 판 사이 틈.** 서로 다른 조각의 경계 | 가슴판과 어깨판 사이 |
| `11 creases` | **파랑, 가늘게** (약 0.5 mm) | **한 판 안의 꺾임**(면이 바뀌는 모서리). 조각은 하나 | 가슴판 가운데 V 능선, 판 가장자리 모따기 |
| `12 hidden / overlap` | **빨강, 점선** | 다른 판 아래로 들어가 **가려진 선**, 겹침 | 어깨판 아래로 들어간 위팔판 윗부분 |
| `13 features` | **초록** | 나사, 통풍구, 루버 슬릿, 조명 선, 각인, 디스크 | 관절 디스크, 상태광 |
| `14 panel IDs` (선택) | 아무 색 글씨 | 판 이름이나 번호 | `T-03 가슴 왼쪽` |
| `15 notes` (선택) | 아무 색 글씨 | 설명 | "여기는 고무", "굽히면 위로 미끄러짐" |

- **판 윤곽은 닫는다.** 판 하나의 테두리가 끊기지 않게 하고, 선끼리 만나는 곳은 스냅으로 정확히 붙인다. 그래야 판을 한 조각씩 정확히 떼어 낼 수 있다.
- **두 줄 선**(판 테두리의 모따기)은 바깥 테두리를 검정, 안쪽 모따기선을 파랑으로 그린다.
- **겹침 방향**: 판 A가 판 B 위에 얹히면 A의 테두리는 검정 실선, B의 가려진 테두리는 빨강 점선으로 그린다. 위아래가 헷갈리면 메모 레이어에 화살표를 그린다.
- **넣지 말 것**:
  - 해칭과 음영 선. 그림자는 분위기 그림에만 넣는다.
  - 같은 선을 여러 번 겹쳐 그은 스케치 선.
  - 원근, 종이 질감, JPEG 압축.

## 6. 뷰끼리 맞추기

1. **정면과 측면을 먼저** 잡는다. 정면이 폭을, 측면이 깊이를 정한다. 둘이 맞아야 나머지가 맞는다.
2. 한 판이 두 뷰에 보이면, 위끝과 아래끝이 **같은 높이선**에 와야 한다.
3. 후면은 정면과 높이가 같아야 한다. 템플릿 높이선을 그대로 쓴다.
4. 팔 4면은 같은 높이(어깨, 팔꿈치, 손목 +)에 맞춘다.
5. 비율은 Claude가 도하 몸에 맞게 조금 조정할 수 있다. 조정한 곳은 % 단위로 보고한다. 템플릿 위에 그리면 조정이 거의 필요 없다.

## 7. 움직일 때 부드럽게

- 관절(어깨, 팔꿈치, 손목, 고관절, 무릎, 발목, 목, 허리) 주변의 판은 **겹치거나 미끄러지거나 비켜 주어야** 한다. 판이 몸에 닿지 않고 서로 부딪히지 않아야 한다.
- 가장 도움이 되는 그림은 **굽힌 자세 한두 장**(팔꿈치 90°, 무릎 90°)이다. 없으면 메모 레이어에 "굽히면 이 판이 저 판 아래로 들어감"을 화살표로 적는다.
- 슈트가 낼 수 있는 동작 범위(현재 설계)
  - 무릎 0~125°, 팔꿈치 0~135°
  - 어깨 굽힘 160°, 벌림 150°
  - 고관절 굽힘 110°
  - 목 회전 ±70°, 숙임 40°
  - 허리 숙임 60°

## 8. 내부 장치와 깊이 (디자인과 공학의 모순 줄이기)

판 아래에는 몸 바깥에 조립되는 장치가 들어간다. 템플릿의 주황 글씨가 그 자리에서 **피부부터 판 바깥면까지 필요한 깊이**다. 현재 공학 추정이고 잠정이다. 디자인이 이보다 얇으면 Claude가 내부 장치를 다시 배치한다. 그래도 이 값을 알고 그리면 디자인과 공학이 처음부터 맞는다.

| 위치 | 필요 깊이 | 들어가는 것 |
|---|---:|---|
| 등 상부 | ≥ 27 mm | 배터리 등판(판 자체가 배터리) + 척추 연산부 |
| 허리 뒤 | ≥ 31 mm | 배전, 교체 버퍼, 냉각 펌프 |
| 엉덩이 뒤 | ≥ 27 mm | 고관절 근육(EHA) |
| 허벅지 앞 | ≥ 29 mm | 무릎 근육(EHA) |
| 종아리 뒤 | ≥ 27 mm | 발목 근육(EHA) |
| 무릎 바깥 | ≥ 15 mm | 교차 4절 링크(+ 디스크 커버) |
| 고관절 옆 | ≥ 35 mm | 고관절 3축 |
| 옆구리 | ≥ 23 mm | 막 아가미 + 루버 팬(옆구리 슬롯이 숨구멍) |
| 가슴 | ≥ 21 mm | 비상 해제 손잡이, 생체 센서 |
| 어깨 위 | ≥ 39 mm | 어깨 중력보상 스프링 |
| 목 옆 | ≥ 23 mm | 팬 박스 |
| 위팔 뒤 | ≥ 23 mm | 팔꿈치 힘줄 구동 |
| 전완 손바닥 쪽 | ≥ 25 mm | 접힌 보조 손 |
| 오른 전완 바깥 / 왼 전완 | ≥ 37 / 31 mm | 툴 베이 / 교체 포트 |

관절 디스크를 그린다면 다음 기능과 연결된다.
- 무릎: 교차 4절 링크 커버
- 팔꿈치: 힘줄 구동 캡스턴
- 발목: 부츠 힌지
- 손목: 수동 베어링 링

## 9. 얼굴(PERSONA)을 그릴 때 기능 요구

얼굴은 도하가 디자인한다. 아래 기능이 들어갈 자리만 고려하면 된다.

- **시야**
  - 눈 구멍이나 슬릿 뒤에 카메라 2대가 있고, 넓은 시야는 카메라가 맡는다. 슬릿은 전원이 꺼져도 남는 예비 시야다.
  - 지난 피드백: 동그란 안경형은 피하고, 얇고 시원하게 긴 눈 구멍.
- **공기**: 헬멧 송풍 160 L/min, 흡기 필터(지난 디자인은 관자놀이 디스크), 날숨 배기(입 쪽).
- **소리**: 골전도 마이크, 스피커.
- **여유**
  - 헬멧 안쪽은 머리에서 최소 12 mm, 권장 20~25 mm. 코끝 앞 12 mm 이상.
  - 턱이 들어갈 공간: 템플릿 3장의 청록 점선 바깥.
- **목**: 목 회전 ±70°를 막지 않는 목 링(라멜라) 또는 틈.
- **연출**: 스토리에서 얼굴판이 마지막에 닫히는 장면(PERSONA LOCK)이 있다. 얼굴판이 어떻게 열리고 닫히는지(내려오는지, 접히는지, 분리되는지) 메모해 주면 좋다.
- **상태광**: 이음선 속 빛줄기(NERVUS)가 지나갈 선이 있으면 표시한다.

## 10. 파일 형식과 보내는 방법

**형식**
1. **SVG**(레이어 유지)가 가장 좋다. Inkscape는 "Inkscape SVG"로 저장한다.
2. 안 되면 **레이어별 PNG**(같은 캔버스 크기, 투명 배경)를 쓴다. Procreate의 "PNG 파일" 내보내기가 정확히 이것이다.
3. 한 장짜리 이미지라면 PNG나 무손실 WebP로, **뷰 하나당 세로 2,000 px 이상**. JPEG는 피한다.

**파일 이름**: `MK1_ref_v1_front.svg`, `MK1_ref_v1_side.svg`, `MK1_ref_v1_arm.svg`, `MK1_ref_v1_helmet.svg`, …

**보내는 방법**
- 이미지(PNG, WebP)는 Claude Code 대화창에 그대로 첨부한다.
- SVG나 파일이 많을 때는 GitHub 저장소 웹 화면에서 `docs/reference/incoming/` 폴더에 업로드한다(Add file → Upload files). 다음 세션이 거기서 읽는다.

## 11. 시간이 부족할 때 우선순위

1. 정면, 후면, 측면(팔 없이)
2. 헬멧 정면·측면·후면과 얼굴
3. 팔 4면
4. 다리 안쪽
5. 굽힌 자세 1장
6. 단면, 상세도, 윗면

1~3만 있어도 지난번보다 훨씬 정확하게 만들 수 있다. 4~6은 정확도와 멋을 더한다.

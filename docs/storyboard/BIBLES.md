# MYOMORPH-MK. 1 — 아트 · 모션 · 사운드 바이블 v1.0

> P1 · 2026-10-02 · 스토리보드 v1.0([`STORYBOARD.md`](STORYBOARD.md))의 규칙집. P3 버티컬 슬라이스에서 이 규칙으로 품질 기준선을 만든다.

## A. 아트 바이블

### A1. 형상의 원천
- **슈트의 모든 판 = 도하의 청사진**. 측면처럼 청사진에 없는 면은 청사진의 문법(관절 끊김, 중앙선, 층 구조)으로 채운다. 얼굴만 PERSONA(내 디자인).
- **보정은 두 곳만**: 팔 축 방향 늘림, 골반 V판 압축. 나머지는 1:1.

### A2. 재질 (스타일프레임 SF1·SF6 기준값, Cycles와 three.js 공용)

- **금지**: 크롬처럼 보이는 저거칠기 대면적, 원인 없는 발광, 겉면 열변색, 만화적 이펙트.

### A3. 팔레트와 타이포
- 배경 그라파이트 `#0A0B0D`~`#15171A`, 청사진 코발트(SCHEMA 전용), UI 강조 시그널 오렌지(아주 적게), 상태광은 NERVUS 체계.
- Geist / Geist Mono(영문 라벨, 데이터, 부품번호), Pretendard(한글 본문). 모두 OFL, 자가 호스팅.
- 라벨은 영문 대문자 + 자간 넓게(`SCHEMA`, `HOLD TO ENGAGE`), 본문은 한글 문장. 숫자는 항상 단위와 함께, 고정폭.

### A4. 조명
- 어두운 스튜디오, 세로 스트립 라이트 2~3개(림 중심), 약한 키, 천장 소프트박스, 광택 바닥. 금속은 무엇을 비추느냐로 보인다: 큰 검정 + 가는 백색 스트립.
- 커서 점검 조명(스폿 9~16°)은 모든 챕터에 존재한다.

## B. 모션 바이블

| 규칙 | 값 |
|---|---|
| 기본 이징 금지 | 모든 움직임은 스프링(질량-감쇠). 선형 트윈 금지 |
| 판 체결 | 접근 280~420 ms(감쇠비 0.75) → 접촉 순간 히트스톱 40 ms → 미세 반동 1 mm 이하 |
| 히어로 판(대흉근, 삼각근, 배터리, PERSONA) | 단독 체결 900~1,400 ms + 너트러너 회전 + 콜아웃 |
| 연쇄 체결 | 간격 45~90 ms, 속도에 따라 그레인 사운드로 전환 |
| 정점 히트스톱 | REVEAL 90 ms, PERSONA LOCK 90 ms + 카메라 임펄스 0.4° |
| 카메라 | 무거운 짐벌: 위치 스프링 ω 2.2 rad/s, 감쇠 0.9. 오버슈트 0.5 % 이하 |
| 스크롤 | 관성 + 디텐트(챕터 경계에서 살짝 걸림). 역스크롤은 완전히 되감김 |
| UI | MYO-UI: 토글은 디텐트 스냅, 페이더는 마찰, 버튼은 0.6 mm 눌림 + 소리 |
| 금지 | 페이드 인으로 나타나는 판(물리적으로 '들어와야' 한다), 이유 없는 회전, 파티클 |

## C. 사운드 바이블 (P0 청음 결정 반영)

- **배경음악 없음.** 기계음, 공간음(룸톤), 정적만.
- **승인된 3종**: 철컥 락 v3(체결의 시그니처), 너트러너 v3(모터 와인 + 클러치), 유압 v2(짧은 '슉', 중간 고음 와인 없음).
- **거칠기 규칙**: 피치를 내리지 않고 **레이어를 겹친다**(AM 20~150 Hz, 디튠 레이어, 미세 충격 포아송 분포).
- **물리 기반**: 판 크기·두께·티타늄 물성으로 고유진동수 계산(모달 합성). 큰 판은 낮고 길게, 작은 판은 높고 짧게.
- **속도 적응**: 천천히 스크롤하면 하나씩 온전히, 빠르면 그레인 래칫으로.
- **동기**: 오디오-비주얼 지연 보정(블루투스 약 170 ms 감지 시 시각 이벤트 지연).
- **믹스**: 피크 −1 dBTP, 통합 −20 LUFS 근처(웹 감상), 저역은 50 Hz 이하 컷(노트북 스피커 보호).

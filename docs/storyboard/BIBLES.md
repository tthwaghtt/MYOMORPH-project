> 도하 피드백 반영: 덜 반짝이게, 약간의 마모, 얇은 눈 슬릿, 천장과 주변의 장비, 압도적인 부품 밀도.

## A. 아트 바이블

### A1. 형상의 원천
- **정면 실루엣과 판 = 도하의 청사진.**
  - 정면에서 커진 곳은 무릎 바깥 5 mm 한 곳뿐이다(4절 링크).
  - 측면 두께는 청사진에 없어서 수납물만큼만 정했다. 정면에서는 보이지 않는다. 표 [`engineering/packaging.json`](../../engineering/packaging.json).
- **기계는 모두 몸 바깥.** 층 순서: 피부 → 언더슈트 → 커프 → 프레임 → 근육(EHA)과 힘줄 → 시스템 → 판. 판은 몸에 닿지 않고 탄소 캐리어 위에 방진 그로밋으로 떠 있다.
- **얼굴만 PERSONA(내 디자인).** 눈은 **얇은 쌍 슬릿**이다.
  - 높이 7 mm(코 쪽)에서 바깥으로 가늘어진다.
  - 바깥으로 11° 올라간다.
  - 길이 약 44 mm.
  - 둥근 바이저는 폐기했다. 변형안 B(코 위가 꺾인 단일 슬릿)와 C(수평 쌍 슬릿)는 [`reviews/P1r2/persona_slits.webp`](../reviews/P1r2/persona_slits.webp).

### A3. 셀 미장센 (빈 곳이 없게, 모두 쓰임새가 있게)
- **천장**:
  - H형강 격자, 갠트리 레일, 드래그 체인
  - 사다리형 트레이 3줄(케이블 18가닥씩), 덕트와 디퓨저, LED 라인 6개
  - 스캐너 링, 탯줄 밸런서, 호이스트, 카메라 4대
- **주변**:
  - 작업대: 토크 공구, 오실로스코프, 노트북, 부품 정리함, 작업등
  - 공구 벽
  - 키팅 카트 2대: 다음에 설치할 모듈이 폼에 담겨 있다
  - 패널 랙
  - 라이트 테이블: **도하의 청사진 원본**
  - 모니터 3대: 실제 데이터로 그린 화면
  - 소화기, 광 커튼, 선반
- **화면 데이터는 진짜 숫자다**: 근전도 채널, 운동단위 37개, 뇌파 32 전극 위치, 시스템별 부품 수가 계산서·부품표와 같다.

### A4. 팔레트와 타이포
- 배경 그라파이트 `#0A0B0D`~`#15171A`, 셀 노랑(로봇, 구역선), 청사진 코발트(SCHEMA 전용), 냉각수 연청, 상태광은 NERVUS 체계, UI 강조 시그널 오렌지(아주 적게).
- Geist / Geist Mono(영문 라벨, 데이터, 부품번호), Pretendard(한글 본문). 모두 OFL, 자가 호스팅.

### A5. 조명
- **셀 전원 OFF(P)**: 손전등 커서 하나와 먼 모니터의 잔광뿐.
- **셀 전원 ON**:
  - 천장 LED 라인 6개
  - 플린스 위 키 스폿 하나
  - 림 스트립 둘
  - 작업등(유일한 따뜻한 빛)
  - 플린스 LED 테두리(차가운 백색)
- 금속은 무엇을 비추느냐로 보인다. 큰 검정 공간과 가는 백색 라인이 무광 티타늄 위에 부드러운 하이라이트를 만든다.

## B. 모션 바이블

| 규칙 | 값 |
|---|---|
| 기본 이징 금지 | 모든 움직임은 스프링(질량-감쇠). 선형 트윈 금지 |
| **로봇 운동학** | 실제 6축 IK + 망원 마스트. 관절 속도 한계(축 1~3: 180°/s, 4~6: 360°/s), 툴 끝 최대 1.2 m/s, 접근 마지막 30 mm는 25 mm/s로 감속. 로봇끼리 충돌 회피(작업 영역 예약) |
| **사전 조립 모듈 설치** | 카트에서 픽 → 이송 → 접근 → 핀·볼트 결합 → 너트러너 → 리트랙트. 모듈 하나 2.5~4 s, 로봇 4대가 겹치게 일한다 |
| 판 체결 | 접근 280~420 ms(감쇠비 0.75) → 접촉 순간 히트스톱 40 ms → 미세 반동 1 mm 이하 |
| 히어로 부품(EHA, 배터리 패널, 흉골 판, PERSONA) | 단독 체결 900~1,400 ms + 시스템 카드 |
| 연쇄 체결 | 간격 45~90 ms, 속도에 따라 그레인 사운드로 전환 |
| **사람의 움직임** | 모션 캡처 기반(STORYBOARD §5). 호흡 0.25 Hz, 대기 중 체중 이동 6~10 s마다. 조립 중에는 로봇에 협조하는 동작만 한다(팔 내밀기, 발 들기, 턱 당기기). 조립 중에도 사람은 사람이다 |
| **패널의 독립적 움직임** | 루버 순차 개방(링크 바 하나, 슬랫 간 위상 40 ms), 측두 허브 회전, 삼각근 캡 층 미끄럼, 복부 밴드 망원 접힘, 무릎 캡 미끄럼, 목 라멜라, 툴 베이(6 mm 슬라이드 후 38° 피벗), 배터리 패널 이탈 |
| 정점 히트스톱 | POWER 90 ms, PERSONA LOCK 90 ms + 카메라 임펄스 0.4°, RELEASE는 히트스톱 없이 정적 1.2 s |
| 카메라 | 무거운 짐벌: 위치 스프링 ω 2.2 rad/s, 감쇠 0.9. 오버슈트 0.5 % 이하 |
| 스크롤 | 관성 + 디텐트(챕터 경계에서 살짝 걸림). 역스크롤은 완전히 되감긴다(조립 해체) |
| UI | MYO-UI: 토글은 디텐트 스냅, 페이더는 마찰, 버튼은 0.6 mm 눌림 + 소리 |
| 금지 | 페이드 인으로 나타나는 부품(물리적으로 '들어와야' 한다), 이유 없는 회전, 파티클, 순간이동하는 로봇 |

## C. 사운드 바이블

- **배경음악 없음.** 기계음, 공간음(룸톤), 사람의 숨, 정적만.
- **승인된 3종 (P0)**:
  - 철컥 락 v3: 체결의 시그니처
  - 너트러너 v3: 모터 와인 + 클러치
  - 유압 v2: 짧은 '슉'
- **R2 신규 카탈로그**:

  | 분류 | 소리 |
  |---|---|
  | 셀 | 릴레이 3연타, LED 드라이버 험, 서보 0점 탐색, 마스트 망원 모터, 드래그 체인 굴림 |
  | 셀 장비 | 스캐너 링 하강, 탯줄 밸런서 감김, 드라이 브레이크 '틱', 공압 이탈 '칙' |
  | 신경 | **운동단위 클릭 트레인**(실제 근전도 청음 방식, 발화율 8~20 Hz), 뇌파 드론(노이즈 필터링, 음악 아님) |
  | 조립 | BOA 래칫, 핀 압입, 서클립, 쿼터턴 '츠칙', 힘줄 장력 크릭, 밸브 전환 |
  | 시스템 | 냉각 펌프, 막 아가미 위 기류, 헬멧 송풍(160 L/min), 팬 6개 기동 |
  | 사람 | 숨, 니트 마찰, 부츠에 발이 들어가는 소리 |

- **거칠기 규칙**: 피치를 내리지 않고 레이어를 겹친다(AM 20~150 Hz, 디튠 레이어, 미세 충격 포아송 분포).
- **물리 기반**: 판 크기·두께·티타늄 물성으로 고유진동수를 계산한다(모달 합성). 큰 판은 낮고 길게, 작은 판은 높고 짧게.
- **속도 적응**: 천천히 스크롤하면 하나씩 온전히, 빠르면 그레인 래칫으로.
- **공간**: 로봇 4대의 소리는 각자의 3D 위치에서 들린다(HRTF). 셀 잔향은 RT60 0.6 s(콘크리트 바닥 + 흡음 천장 가정).
- **믹스**: 피크 −1 dBTP, 통합 −20 LUFS 근처, 50 Hz 이하 컷.

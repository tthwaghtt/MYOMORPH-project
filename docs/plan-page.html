Project plan · v1.3 · 2026-10-02

MYOMORPH-MK. 1

NOT ARMOR. ANATOMY.

근육 해부도를 티타늄 패널로 입체화한, 실제로 작동 가능한 근골격 슈트. 이 슈트를 주인공으로 마우스와 스크롤에 반응하는 3D 웹 경험을 만든다. 이 페이지는 전체 계획과 지금 위치를 한눈에 보기 위한 요약이다.

현재 위치

P1 프리프로덕션을 마치고 G1 검토를 기다립니다. 착용자(도하) 정밀 분석, 청사진 기반 슈트 디자인, PERSONA 얼굴, 스타일프레임 8장, 계산서, 스토리보드 v1.0을 끝냈습니다. 도하가 승인하면 P2로 갑니다.

전체 단계

각 단계가 끝나면 도하가 결과를 보고 승인하는 게이트(G0~G7)가 있다. 승인이 나야 다음 단계로 넘어간다.

계획 · 설계
  1. ✓

    브리프 해석과 마스터 플랜 완료

    스토리, 슈트 설계, 실사화 전략, 기술 구조, 일정, 리스크. 드로잉 실측 분석 포함.

  2. ✓

    블렌더 방법론 조사 승인됨

    Blender 5.2.1 실행 확인, 업계 작업 방식 조사, 색과 재질 수치 실측, 작업 규약(MBS) 작성.

  3. ✓

    환경 시험 완료

    Mac과 iPhone에서 3D 렌더러, 압축 모델, 색 LUT, 소리, iPhone 햅틱 통과. 도하 피드백으로 소리를 새로 만들었고 자동 조립 로봇팔을 스토리에 추가했다.

  4. P1

    프리프로덕션 완료 · G1 검토 대기

    도하의 몸 분석(체성분, 93개 치수, 근육 표)과 맞춘 마네킹, 패널 디자인은 도하의 청사진 그대로(정면 211·후면 102 영역), 몸에 맞춘 보정 두 곳(팔, 가랑이), PERSONA 얼굴, 스타일프레임 8장, 계산서(약 51 kg), 스토리보드 v1.0.

    도하가 할 일 보정 두 곳, PERSONA, 골드 포인트, 측면 두께, 상태광 색 확인

제작
  1. P2

    몸과 비율 잡기 G2

    제작용 착용자 몸과 리그, 청사진에서 슈트 외형을 정밀 모델링(정면·후면 겹침 검증, 측면도 설계), 패널 분할선 곡선망, 가동 범위 충돌 검사.

    도하가 할 일 실루엣, 측면도, 비율 승인

  2. P3

    오른팔 한 개를 최종 품질로 G3 · 가장 중요

    어깨부터 손까지, 툴 베이와 보조 손 포함. 웹에서 조립 애니메이션, 소리, 손맛까지 실제로 동작하게 만든다.

    도하가 할 일 직접 보고 듣고 만져본 뒤 품질 기준 확정. 이 수준을 전신에 복제한다

  3. P4

    전신 제작 G4

    다리, 골반, 몸통, 목, PERSONA 마스크, 왼팔, 내부 기계. 부품 4,000개 이상.

  4. P5

    웹 경험 전체 구현 G5

    13개 챕터, 카메라 연출, 관찰 모드, 모든 버튼과 입력란의 모션.

  5. P6

    사운드와 손맛 G6

    체결음 전체, 믹싱, 진동 패턴, 스크롤 감각 튜닝.

    도하가 할 일 실제 기기로 듣고 느낀 피드백 (저는 소리를 들을 수 없습니다)

출시

    성능 최적화, 여러 브라우저와 모바일 확인, 최종 웹페이지 발행.

재질 방향

도하가 보내준 사진 다섯 장을 반영했다. 열변색은 실제로 열이 나는 곳에만 넣어서 자연스럽게 녹아들게 한다.

티타늄 (기본)비드블라스트 무광. 슈트 대부분의 근육 패널.
유광 골드 (TiN)체결부품, 관절 링, 피스톤 로드 같은 작은 기계 부품.
헤어라인 골드근육 패널의 골드 포인트. 결 방향 = 근섬유 방향.
열변색프레임 용접부, 유압 펌프 배기구, 엉덩이 냉각 루버 안쪽. 보는 각도에 따라 색이 변하게 렌더한다.

결정 사항

확정

  • 마스크: 드로잉 실루엣 + 안면근 기반 오리지널 PERSONA
  • Blender 5.2.1 LTS (이 환경에서 실행 확인)
  • 색 일치: Blender AgX를 LUT로 웹에 적용
  • 재질: 티타늄 기본 + 골드 포인트 + 열변색 디테일
  • 조립 로봇팔: 페인트가 살짝 벗겨진 노란색
  • 소리: 체결 철컥, 로봇팔 너트러너, 유압 (P0 청음으로 확정)
  • 성능 목표: 데스크톱 60 fps, 모바일 30 fps
  • 패널 디자인 = 도하의 청사진 (얼굴만 PERSONA)
  • 원본 드로잉을 크레딧과 함께 사이트에 (01 SCHEMA)
  • 영문 라벨 + 한글 본문, 배경음악 없음
  • 크레딧: 도면 표제란 + 숨은 각인 + 출처 목록

G1에서 정하면 되는 것

  • 청사진 보정 두 곳 (팔 길이, 가랑이 높이)
  • PERSONA 얼굴 디자인
  • 골드 포인트 5종
  • 측면 두께 방향 (청사진에 측면도 없음)
  • 상태광 색 (구동 중 = 시안 가안)
  • 최종 페이지 공개 범위 (P7까지)
다음 행동

도하가 스토리보드 페이지와 G1 항목을 검토한다. 승인되면 P2(제작용 몸, 청사진 외형 정밀 모델링, 측면도)를 시작한다.

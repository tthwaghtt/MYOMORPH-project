Project plan · v2.0 · 2026-10-03

MYOMORPH-MK. 1

NOT ARMOR. ANATOMY.

근육 해부도를 티타늄 패널로 입체화한, 실제로 작동 가능한 근골격 슈트. 어둠 속 조립 셀에서 천장의 로봇팔들이 한 사람의 몸 바깥에 이 슈트를 조립하는 과정을, 마우스와 스크롤에 반응하는 웹 경험으로 만든다. 이 페이지는 전체 계획과 지금 위치를 한눈에 보기 위한 요약이다.

현재 위치

P1 프리프로덕션을 도하 피드백에 맞춰 다시 짰고(R2), G1 재검토를 기다립니다. 사람이 먼저 나오는 스토리, 몸 바깥에 층으로 쌓는 슈트 구조(부품 5,819개, 모듈 41개), 슬림 실루엣 안 공간 검사, 신경 언더슈트, 얇은 눈 슬릿, 무광과 사용 흔적, 조립 셀, 스타일프레임 11장, 하이브리드 렌더 계획을 끝냈습니다.

전체 단계

각 단계가 끝나면 도하가 결과를 보고 승인하는 게이트(G0~G7)가 있다. 승인이 나야 다음 단계로 넘어간다.

계획 · 설계
  1. ✓

    브리프 해석과 마스터 플랜 완료

    스토리, 슈트 설계, 실사화 전략, 기술 구조, 일정, 리스크. 드로잉 실측 분석 포함.

  2. ✓

    블렌더 방법론 조사 승인됨

    Blender 5.2.1 실행 확인, 업계 작업 방식 조사, 색과 재질 수치 실측, 작업 규약(MBS) 작성.

  3. ✓

    환경 시험 완료

    Mac과 iPhone에서 3D 렌더러, 압축 모델, 색 LUT, 소리, iPhone 햅틱 통과. 체결음, 너트러너, 유압 소리 확정.

  4. P1

    프리프로덕션 R2 개정 완료 · G1 재검토 대기

    R1: 도하의 몸 분석과 맞춘 마네킹, 청사진 판 477장, 착용 보정, PERSONA. R2: 사람이 먼저인 스토리 v2.0, 몸 바깥 층 구조(13 시스템, 모듈 41, 부품 5,819), 공간 검사 53/53, 근전도·뇌파 언더슈트, 얇은 눈 슬릿, 무광과 마모, 조립 셀, 스타일프레임 11장.

    도하가 할 일 스토리 구조, 언더슈트 룩, 눈 슬릿 안(A/B/C), 성능 축소 폭, 무릎 +5 mm, 배터리 패널, 외부 연결 범위, 마모 정도 확인

제작
  1. P2

    자산 기반과 파이프라인 증명 G2

    제작용 몸과 모션, 언더슈트 제작 모델, 슈트 외형 정밀 모델과 측면도, 판 솔리드화 시제품(오른팔), 모듈 라이브러리(무릎 근육, 배터리 패널, 막 아가미 우선), 조립 셀과 로봇 리그, 미리 렌더한 프레임을 스크롤로 재생하는 파이프라인 시험, 렌더 시간 실측.

    도하가 할 일 비율, 측면도, 사람과 언더슈트 룩 승인, 렌더 방법 결정(이 환경 / 도하 PC GPU / 클라우드)

  2. P3

    한 챕터를 최종 품질로 G3 · 가장 중요

    06 MUSCLE: 로봇이 무릎 근육을 도하의 허벅지에 설치하고, 시험 동작, 분해 카드, 호버, 소리까지. 어둠과 손전등 오프닝, 판 체결 한 장면 포함.

    도하가 할 일 직접 보고 듣고 만져본 뒤 품질 기준 확정

  3. P4

    전체 제작 G4

    모듈 41개와 판 477장(나사 1,458개), 헬멧, 로봇 4대와 사람의 조립 애니메이션, 패널의 독립적 움직임.

  4. P5

    경험 제작과 렌더 G5

    조립 장면 프레임 렌더(약 2,640장), 16개 챕터, 실시간 레이어, 시스템 카드, 놀링, 자유 탐색.

  5. P6

    사운드와 손맛 G6

    체결음, 근육 신호음, 탯줄과 루버 소리, 믹싱, 진동, 스크롤 감각.

    도하가 할 일 실제 기기로 듣고 느낀 피드백 (저는 소리를 들을 수 없습니다)

출시
  1. P7

    다듬기와 발행 G7

    성능 최적화, 여러 브라우저와 모바일 확인, 최종 웹페이지를 여러 번에 나눠 발행.

무엇을 만드나

약 290초스크롤 감상 분량 (요청 100초)
5,819부품 (모듈 41개, 판 477장)
36.6 kg슈트 질량 (사람이 입는 것 1.92 kg)
3.7 h배터리 패널 0.84 kWh로 케이블 없이

완성된 슈트는 처음에 나오지 않는다. 어둠 속 조립 셀에서 손전등 커서가 로봇과 케이블과 사람을 찾고, 조명이 켜지면 레이싱 슈트형 언더슈트와 바라클라바를 입은 도하가 서 있다. 로봇팔들이 몸 바깥에 부츠, 뼈대, 근육, 시스템, 판, 헬멧을 조립하고, 탯줄이 빠지는 순간 완성된 슈트가 처음으로 전신을 드러낸다.

재질 방향

도하 피드백대로 덜 반짝이게, 가볍게 쓴 흔적을 넣는다. 열변색은 실제로 열이 나는 곳에만 쓴다.

무광 티타늄 (기본)비드블라스트. 가장자리는 손에 닳아 매끈하고, 이음선 옆에는 먼지가 앉고, 드물게 긁힘.
새틴 골드 (TiN)포인트 5곳. 가장자리에서 코팅이 닳아 티타늄이 비친다.
그라파이트 니트언더슈트. 봉제선, 대비 스티치, 견장, 은사 배선, 점 무늬 센서 패드.
열변색용접부와 근육 모터 하우징 같은 숨은 곳에만.

결정 사항

확정

  • 마스크: 드로잉 실루엣 + 안면근 기반 오리지널 PERSONA
  • Blender 5.2.1 LTS, 색 일치는 AgX LUT
  • 조립 로봇팔: 페인트가 살짝 벗겨진 노란색, 천장에 매달림
  • 소리: 체결 철컥, 너트러너, 유압 (P0 확정), 배경음악 없음
  • 성능 목표: 데스크톱 60 fps, 모바일 30 fps
  • 패널 디자인 = 도하의 청사진 (얼굴만 PERSONA)
  • 영문 라벨 + 한글 본문, 크레딧은 도면 표제란
  • 완성은 끝에, 조립 셀로 시작 (2026-10-03)
  • 슬림 실루엣 유지, 성능 축소, 배터리는 패널, 케이블은 불가피할 때만 (2026-10-03)
  • 겉은 레이싱 슈트, 속은 근전도·냉각 기능성 (2026-10-03)
  • 렌더: 하이브리드 (2026-10-03)

G1 재검토에서 정하면 되는 것

  • 스토리 v2 구조 (정점 3개, 약 290초)
  • 언더슈트와 바라클라바 룩
  • 눈 슬릿 안 A / B / C
  • 성능 축소 폭 (보조 25 %, 3.7시간, 36.6 kg)
  • 무릎 바깥 +5 mm (정면 실루엣이 커지는 유일한 곳)
  • 배터리 패널 = 등판, 외부 연결 범위, 마모 정도
  • 골드 포인트 5종, 상태광 색

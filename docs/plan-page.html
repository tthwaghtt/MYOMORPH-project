Project plan · v3.0 · 2026-10-03

MYOMORPH-MK. 1

NOT ARMOR. ANATOMY.

실제로 작동 가능한 근골격 티타늄 슈트. 어둠 속 조립 셀에서 천장의 로봇팔들이 한 사람의 몸 바깥에 이 슈트를 조립하는 과정을, 마우스와 스크롤에 반응하는 웹 경험으로 만든다. 슈트의 외형과 헬멧은 도하의 레퍼런스를 그대로 따른다. 이 페이지는 전체 계획과 지금 위치를 한눈에 보기 위한 요약이다.

현재 위치

마네킹 기반 슈트 디자인을 폐기하고, 도하의 새 레퍼런스로 슈트를 다시 만들 준비를 마쳤습니다. 레퍼런스를 기다립니다. 레퍼런스 작성 가이드와 도하 몸 치수 템플릿 3장, 파일 정리와 폐기물의 git 기록 삭제, 계획서 v3.0, 새 세션 인계 문서, 레퍼런스 처리 절차를 끝냈습니다. 의도, 몸 치수, 동작 원리, 공학, 언더슈트, 기능, 색, 소리, 웹 디자인은 그대로입니다.

왜 레퍼런스 기반으로 바꾸나

지난 슈트는 정면 청사진의 2D 선을 마네킹 피부를 부풀린 한 장의 껍데기에 투영해서 만들었다. 그래서 판이 독립된 조각이 되지 못했다. 이번에는 도하가 모든 면을 그린 레퍼런스에서 판을 하나씩 직접 만든다.

지난 방식의 문제이번 방식
해칭과 두 줄 선이 전부 이음선이 됨선의 뜻을 색과 레이어로 나눈다(판 틈, 꺾임, 겹침, 부품)
경계가 계단 모양, 이음선이 끊김벡터 도면. 판은 홈이 아니라 따로 만든 솔리드
한 장의 껍데기에 홈을 낸 판판마다 두께, 헴, 모따기, 틈, 겹침 순서
정면·측면 한 장씩이라 안쪽과 옆면을 추측정면, 후면, 측면, 팔 4면, 다리 안쪽, 헬멧 4면 + 얼굴
  1. 받기와 검토빠진 뷰와 질문 목록을 보고하고 동의를 받는다
  2. 뷰별 벡터화선 종류별로 나눠 읽는다
  3. 뷰 정합높이선으로 뷰끼리, 몸과 맞춘다
  4. 판 목록과 판 솔리드한 부위를 먼저 만들어 확인받는다
  5. 비율 조정 보고5 %를 넘으면 먼저 묻는다
  6. 공간·가동 범위 검사장치 깊이와 관절 간섭, 충돌 목록
  7. 수치 다시 계산부품, 질량, 근육, 전력, 가동 시간
  8. 검토 렌더레퍼런스 위에 겹친 정사영 렌더
  9. 스토리보드와 페이지 갱신조금씩, 한 번에 완성하지 않는다

금색 테두리 도하에게 보고하고 동의를 받은 뒤 넘어가는 단계

전체 단계

각 단계가 끝나면 도하가 결과를 보고 승인하는 게이트(G0~G7)가 있다. 승인이 나야 다음 단계로 넘어간다.

계획 · 설계
  1. ✓

    브리프 해석과 마스터 플랜 완료

    스토리, 슈트 설계, 실사화 전략, 기술 구조, 일정, 리스크. 드로잉 실측 분석 포함.

  2. ✓

    블렌더 방법론 조사 승인됨

    Blender 5.2.1 실행 확인, 업계 작업 방식 조사, 색과 재질 수치 실측, 작업 규약(MBS) 작성.

  3. ✓

    환경 시험 완료

    Mac과 iPhone에서 3D 렌더러, 압축 모델, 색 LUT, 소리, iPhone 햅틱 통과. 체결음, 너트러너, 유압 소리 확정.

  4. P1

    프리프로덕션 R3 준비 완료 · 레퍼런스 대기

    R1: 도하의 몸 분석과 맞춘 마네킹. R2: 사람이 먼저인 스토리 v2.0, 몸 바깥 층 구조(13 시스템, 모듈 41, 부품 5,819), 근전도·뇌파 언더슈트, 무광과 마모, 조립 셀. 마네킹으로 만든 슈트 외형, 헬멧, 스타일프레임은 폐기했다. R3: 레퍼런스 가이드와 템플릿, 계획서 v3.0, 인계 문서, 처리 절차. 레퍼런스가 오면 위의 9단계로 판 모델을 만들고 G1에서 함께 본다.

    도하가 할 일 가이드대로 레퍼런스 그리기(정면, 후면, 측면, 팔 4면, 다리 안쪽, 헬멧 4면 + 얼굴) → GitHub의 docs/reference/incoming/에 올리거나 대화에 첨부 → 새 세션 열기(첫 메시지는 HANDOFF §1.2)

제작
  1. P2

    자산 기반과 파이프라인 증명 G2

    제작용 몸과 모션, 언더슈트 제작 모델, 레퍼런스 판 모델을 제작 수준으로(헴, 체결점, 안쪽 면), 헬멧 정밀 모델, 모듈 라이브러리(무릎 근육, 배터리 패널, 막 아가미 우선), 조립 셀과 로봇 리그, 미리 렌더한 프레임을 스크롤로 재생하는 파이프라인 시험. 프레임 렌더 실측 추정: 이 환경 CPU 약 120~280시간, GPU 약 6~28시간.

    도하가 할 일 사람과 언더슈트 룩, 판 제작 디테일 승인, 렌더 방법 결정(이 환경 / 도하 PC GPU / 클라우드)

  2. P3

    한 챕터를 최종 품질로 G3 · 가장 중요

    06 MUSCLE: 로봇이 무릎 근육을 도하의 허벅지에 설치하고, 시험 동작, 분해 카드, 호버, 소리까지. 어둠과 손전등 오프닝, 판 체결 한 장면 포함.

    도하가 할 일 직접 보고 듣고 만져본 뒤 품질 기준 확정

  3. P4

    전체 제작 G4

    모듈 41개와 레퍼런스의 판 전체(나사 포함), 헬멧, 로봇 4대와 사람의 조립 애니메이션, 판의 독립적 움직임.

  4. P5

    경험 제작과 렌더 G5

    조립 장면 프레임 렌더(약 2,640장), 16개 챕터, 실시간 레이어, 시스템 카드, 놀링, 자유 탐색.

  5. P6

    사운드와 손맛 G6

    체결음, 근육 신호음, 탯줄과 루버 소리, 믹싱, 진동, 스크롤 감각.

    도하가 할 일 실제 기기로 듣고 느낀 피드백 (저는 소리를 들을 수 없습니다)

완성된 슈트는 처음에 나오지 않는다. 어둠 속 조립 셀에서 손전등 커서가 로봇과 케이블과 사람을 찾고, 조명이 켜지면 레이싱 슈트형 언더슈트와 바라클라바를 입은 도하가 서 있다. 로봇팔들이 몸 바깥에 부츠, 뼈대, 근육, 시스템, 판, 헬멧을 조립하고, 탯줄이 빠지는 순간 완성된 슈트가 처음으로 전신을 드러낸다.

재질 방향

도하 피드백대로 덜 반짝이게, 가볍게 쓴 흔적을 넣는다. 열변색은 실제로 열이 나는 곳에만 쓴다.

무광 티타늄 (기본)비드블라스트. 가장자리는 손에 닳아 매끈하고, 이음선 옆에는 먼지가 앉고, 드물게 긁힘.
새틴 골드 (TiN)포인트에만. 위치는 레퍼런스를 따른다. 가장자리에서 코팅이 닳아 티타늄이 비친다.
그라파이트 니트언더슈트. 봉제선, 대비 스티치, 견장, 은사 배선, 점 무늬 센서 패드.
열변색용접부와 근육 모터 하우징 같은 숨은 곳에만.

결정 사항

확정

  • Blender 5.2.1 LTS, 색 일치는 AgX LUT
  • 조립 로봇팔: 페인트가 살짝 벗겨진 노란색, 천장에 매달림
  • 소리: 체결 철컥, 너트러너, 유압 (P0 확정), 배경음악 없음
  • 성능 목표: 데스크톱 60 fps, 모바일 30 fps
  • 슈트 외형 = 도하의 새 레퍼런스 그대로, 마네킹 기반 디자인 폐기 (2026-10-03)
  • 헬멧과 얼굴(PERSONA)도 도하가 디자인 (2026-10-03)
  • 도구(Blender, three.js) 유지, 폐기한 디자인의 git 기록 삭제 (2026-10-03)
  • 스토리보드는 아이디어에 따라 조금씩 고친다 (2026-10-03)
  • 영문 라벨 + 한글 본문, 크레딧은 도면 표제란
  • 완성은 끝에, 조립 셀로 시작 (2026-10-03)
  • 슬림 실루엣 유지, 성능 축소, 배터리는 패널, 케이블은 불가피할 때만 (2026-10-03)
  • 겉은 레이싱 슈트, 속은 근전도·냉각 기능성 (2026-10-03)
  • 렌더: 하이브리드 (2026-10-03)
